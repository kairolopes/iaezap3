🔌 ENDPOINTS INTEGRADOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POST   /agents/:companyId         → Criar novo agente
GET    /agents/:companyId         → Listar agentes
GET    /agents/detail/:id         → Obter um agente
PUT    /agents/:id                → Atualizar agente
DELETE /agents/:id                → Deletar agente
GET    /agents/meta/roles         → Obter roles (TRIAGE, SALES, etc)
GET    /agents/meta/tones         → Obter tones (FRIENDLY, PROFESSIONAL, etc)

📋 CAMPOS DO AGENTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Obrigatórios:
  • name          (string)        - Nome do agente
  • role          (select)        - Função (TRIAGE, SALES, SCHEDULING, SUPPORT)
  • tone          (select)        - Tom (FRIENDLY, PROFESSIONAL, FORMAL, FUNNY)

Opcionais:
  • personality   (string)        - Personalidade do agente
  • instructions  (string)        - Instruções e comportamento
  • maxDiscount   (number 0-100)  - Desconto máximo
  • canRespond24h (boolean)       - Responder 24 horas
  • canCreateOrder (boolean)      - Criar pedidos
  • canSchedule   (boolean)       - Agendar

🚀 COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Iniciar frontend:
   $ cd frontend
   $ npm run dev
   Acessa http://localhost:5173

2. Fazer login

3. Clicar em "Agentes" na sidebar

4. Interagir com a interface:
   ➕ Criar novo agente     (clique no botão)
   ✏️  Editar agente        (clique no botão do card)
   🗑️  Deletar agente       (clique no botão do card)

📊 FLUXO DE DADOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Criar Agente:
  User clica "Criar" → Modal abre → Preenche form → Clica "Salvar"
  → POST /agents/:companyId → Backend cria → Lista atualiza

Editar Agente:
  User clica "Editar" → Modal abre com dados → Modifica → Clica "Salvar"
  → PUT /agents/:id → Backend atualiza → Lista atualiza

Deletar Agente:
  User clica "Deletar" → Confirma → DELETE /agents/:id
  → Backend deleta → Lista atualiza

  → Verificar se estão em frontend/src/components/

Erro: 401 Unauthorized
  → Verificar se token é válido
  → Fazer login novamente

Erro: 404 endpoints
  → Verificar se backend está rodando em localhost:3000
  → Testar: curl http://localhost:3000/agents/meta/roles

Selects vazios
  → Verificar endpoints /agents/meta/roles e /agents/meta/tones
  → Ver console do navegador (F12)

Modal não fecha
  → Clicar no X (✕) ou botão "Cancelar"
