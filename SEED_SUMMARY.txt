                      VERIFICAR DADOS (SQL)
================================================================================

-- Ver master user
SELECT id, email, role FROM auth.users
WHERE email = 'kairo@zapbaratinho.com.br';

-- Ver profile
SELECT * FROM profiles
WHERE email = 'kairo@zapbaratinho.com.br';

-- Ver company
SELECT * FROM companies
WHERE name = 'Floral da Esquina';

-- Ver agents
SELECT id, name, role, is_active FROM agents
WHERE company_id = (
  SELECT id FROM companies
  WHERE name = 'Floral da Esquina'
) ORDER BY role;

-- Contar registros
SELECT
  (SELECT COUNT(*) FROM auth.users) as users,
  (SELECT COUNT(*) FROM profiles) as profiles,
  (SELECT COUNT(*) FROM companies) as companies,
  (SELECT COUNT(*) FROM agents) as agents;

================================================================================
                      OBSERVAÇÕES
================================================================================

✓ Script é idempotente - seguro rodar múltiplas vezes
✓ Usa ON CONFLICT DO NOTHING para evitar duplicatas
✓ Requer extensão pgcrypto no PostgreSQL (padrão no Supabase)
✓ UUIDs são gerados automaticamente pelo PostgreSQL
✓ Timestamps usam NOW() para data/hora atuais

⚠ Se receber erro de permissão ao criar user em auth.users:
  1. Crie o user manualmente via Supabase Dashboard
  2. O resto do seed funcionará normalmente
